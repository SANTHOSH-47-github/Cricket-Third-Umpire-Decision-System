# Cricket-Third-Umpire-Decision-System
This project is developed to recreate the cricket third umpire review process using video processing techniques. The system helps analyze match clips and display final decisions like OUT or NOT OUT similar to real DRS systems.

✨ Key Features
Video replay controls
Slow motion analysis
Forward and backward frame navigation
Third umpire decision screen
Simple and interactive interface

💻 Technologies Used
Python
OpenCV
Flask
HTML, CSS, JavaScript
🎯 Objective

The main aim of this project is to demonstrate the use of computer vision and video analysis in sports applications.
